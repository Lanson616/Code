## 项目结构 ##

项目根目录包含本 README、更新日志（CHANGELOG.md）、运行产物 output/；
所有源代码在 code/ 子目录中，已拆分为多个模块，入口是 code/main.py：

| 文件（均在 code/ 内） | 职责 |
|---|---|
| main.py | 主流程：选地图 → 选算法 → 单人搜索 → 双人搜索 → 动画输出 |
| constants.py | 常数与共享状态（地图、转头角度、输出路径等），供各模块统一读写 |
| user_input.py | 用户输入：支持预设地图、随机地图、txt文件输入、地图绘制器 |
| map_loader.py | 解析地图文件、地图随机生成、地图保存（save_map / map_to_text） |
| map_editor.py | 地图绘制器：点击画墙（黑白切换）、选守卫起点（红色），可独立启动也可被 user_input 引用；画完可保存进 maps/ |
| maps/ | 预设示例地图库（code/maps/，.txt 文件，见下方格式说明） |
| simulation.py | 视觉判定（遮挡 / 可见性 / 视野位掩码，均带缓存）与运行规则（安全性检查、动作系统） |
| search_registry.py | 搜索算法注册表，可直接接入新算法 |
| BFS_search.py | BFS 搜索算法（单人 / 双人，带步数上界剪枝） |
| visualization.py | 可视化: 路径重放与动画（渐变手电筒视野锥） |
| test.py | 算法对比基准：像 main 一样输入，对所有注册算法计时跑同样的任务；输出对比表格（最少人数/步数/守卫面向/单双人耗时），并生成对比图 |
| output/ | 运行产物：single.gif / double.gif（动画）、solution.txt（最优路径）、comparison.png（对比图） |

## 地图文件格式 ##

code/maps/ 里的预设和任意自定义地图都用同一格式（.txt）：

```
# 以 # 开头是注释，空行跳过
S....
.###.
.###.
.###.
.....
```

- `.` 或 `0` = 空地，`#` 或 `1` = 墙，`S` = 守卫起点（省略 S 则运行时手动输入起点坐标）
- 每行字符数 = 地图宽度，行数 = 高度；左上角是 (0,0)，x 向右，y 向下
- 地图大小一律从内容自动读取，任何来源都不需要手动输入长宽

预设说明：tiny（带中心柱，单人 4 步）/ ring（回字形，单人 10 步）单人可解，演示快；hall / plus / rooms 单人无解，运行会进入较慢的双人搜索。

## 运行方式 ##

```
cd code
python3 main.py        # 选地图、选算法，求解并播放动画，结果导出到 output/
python3 test.py        # 对所有注册算法做性能对比，输出表格和对比图
python3 map_editor.py  # 独立启动地图绘制器，画完默认保存到 maps/
```

## 输出示例 ##

main.py 求解输出（求解结果 + 耗时统计）：

```
========== 求解结果 ==========
最少人数 : 1
最少步数 : 12
守卫面向 : 0°

耗时统计：
阶段        耗时(ms)      步数
单人搜索      6.2         12
总计        6.2
最优路径已导出到 output/solution.txt
```

solution.txt 内容：

```
算法: BFS
最少人数: 1
守卫初始面向: 0°
最少步数: 12
最优路径: ['right', 'right', 'anticlock', 'up', ...]
```
